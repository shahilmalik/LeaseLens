# LeaseLens Frontend (Next.js)

```bash
npm install
npm run dev
```

Open http://localhost:3000.

The backend API base URL can be configured via `NEXT_PUBLIC_API_URL`
(defaults to `http://localhost:8000/api/v1`).

## Flow

`/` → `/login` → `/select-language` → `/upload` → `/dashboard`

See the root `README.md` for the project-wide coding conventions.
